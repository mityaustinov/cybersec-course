## Code
You can add code pieces to the markdown. They can be inline: `# comment it is. trust me you must.`

Or they can be code blocks. General ones...
```
// Continue coding below this line.
```

... or some specific language, for example JavaScript:

```javascript
console.log('Hello, world!')
```

To specify a language, it must be mentioned like so:

~~~~md
```md
This is a code block, that explains how to highlight a code block for specific language, MarkDown in this case. 
```
~~~~
